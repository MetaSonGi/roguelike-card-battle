# 🃏 로그라이크 카드 배틀

발라트로(Balatro) 스타일의 포커 족보 × 덱빌딩 로그라이크 카드 게임.
52장 표준 덱으로 족보를 만들고, 조커를 모아 점수를 불려 8라운드를 돌파하세요.

## 플레이 방법

1. 매 라운드 8장의 손패가 주어집니다.
2. 카드를 눌러 선택(최대 5장, 선택 순서 표시) → 선택된 카드의 **족보명과 예상 점수가 실시간으로 미리보기**에 표시됩니다.
3. **플레이**: 선택한 카드를 제출해 점수 획득. 점수 = 칩(족보 기본점 + 카드 숫자 합) × 멀트(족보 배율)
4. **버리기**: 선택한 카드를 버리고 새로 뽑기 (라운드당 3회)
5. 라운드당 플레이 4회 안에 **목표 점수(블라인드)** 를 넘기면 클리어!
6. 클리어 후 **상점**에서 조커 3종 중 1장을 선택해 덱에 추가합니다.
7. 8라운드(앤티) 돌파 시 승리, 목표 점수 미달 시 게임 오버. 최고 라운드 기록이 브라우저에 저장됩니다.

## 족보 (낮은 순)

하이카드 → 원페어 → 투페어 → 트리플 → 스트레이트 → 플러시 → 풀하우스 → 포카드 → 스트레이트 플러시

- 스트레이트는 A-2-3-4-5(휠) 포함
- 스트레이트·플러시·스트레이트 플러시는 5장 플레이 시에만 성립
- 카드 칩: 숫자 그대로, J/Q/K=10, A=11

## 조커 8종

| 조커 | 효과 |
|---|---|
| 페어 마스터 | 페어 계열 플레이 시 멀트 +4 |
| 하트 러버 | 플레이한 ♥ 1장당 칩 +10 |
| 스트레이트 킬러 | 스트레이트 이상 플레이 시 멀트 ×2 |
| 플러시 헌터 | 플러시 이상 플레이 시 칩 +25 |
| 에이스 킹 | 플레이한 A 1장당 칩 +15 |
| 포카드 브레이커 | 포카드 플레이 시 멀트 ×3 |
| 하이롤러 | 하이카드 플레이 시 칩 +30 |
| 클럽 파이터 | 플레이한 ♣ 1장당 멀트 +1 |
